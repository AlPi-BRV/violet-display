Violet Pool-Display

Firmware für das Elecrow CrowPanel 5" (DIS07050H) – direkt im Browser flashen

  1. Display per USB-C mit dem Rechner verbinden.
  2. Diese Seite in Chrome oder Edge öffnen (Firefox und Safari können kein USB).
  3. Auf Installieren klicken und den Anschluss des Displays wählen.
Dieser Browser kann nicht flashen – bitte Chrome oder Edge verwenden.

Startet die Verbindung nicht: am Display BOOT gedrückt halten, kurz RESET drücken, BOOT loslassen.

Nach dem Flashen

Das Display öffnet die Einstellungen von selbst. WLAN suchen und Passwort eingeben, dann im Reiter „Violet“ die IP der Violet sowie Benutzer und Passwort eintragen. Später erreichst du die Einstellungen, indem du die Kopfzeile 2 Sekunden gedrückt hältst.

Beim Aktualisieren fragt das Tool, ob das Gerät gelöscht werden soll. Mit „Nein“ bleiben die Einstellungen erhalten.

Kein offizielles Produkt von PoolDigital. Nutzung auf eigene Gefahr. Quellcode und Anleitung: github.com/AlPi-BRV/violet-display
